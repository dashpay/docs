Third Party Wallets
===================

These wallets have been developed by external developers to support
Dash. Many third party wallets support multiple different
cryptocurrencies at the same time, or integrate instant cryptocurrency
exchanges.

The Dash website maintains the current list of third party wallets
supporting Dash at https://www.dash.org/download/. Please note that Dash
does not provide support for any of these wallets, and any listing
should not be considered an endorsement or recommendation. Contact the
software vendor for support.
